Data notes

The published dashboard is rebuilt from the newest valid filename matching shared-text-YYYY-MM-DD HH_MM_SS.mmm.csv. Older exports remain archived in the repository and are excluded from the live page.

PvP percentages are Poke Genie IV rankings for eligible league evolutions. They do not measure the current battle meta. Missing values indicate that Poke Genie did not provide a usable value in the source export.
