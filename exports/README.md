# Archived Poke Genie exports

Upload each Poke Genie CSV export to this directory without renaming it.

Accepted filename format:

```text
shared-text-YYYY-MM-DD HH_MM_SS.mmm.csv
```

The GitHub Pages workflow scans the archive and publishes only the single newest timestamped file. Older exports remain in this directory as history.

Do not place credentials, private notes, location data, or unrelated personal files here because this repository is public.
